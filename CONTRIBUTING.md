## Issue Guidelines

### Which template should I use?

Ask yourself: **"Did this ever work correctly?"**

- **YES, but it's broken now** → Use the **Bug Fix** template
- **NO, I want something new** → Use the **Enhancement** template  
- **I have an idea but need discussion** → Use the **Recommendation** template
- **None of the above** → Use the **General** template
